# 🧁 Sistema de Gestão para Confeiteiras Autônomas

Aplicação web criada para **facilitar o dia a dia de confeiteiras autônomas**, reunindo em um só lugar o controle de encomendas, clientes, produtos, receitas, estoque e agenda, sem planilhas espalhadas e sem anotações perdidas.
---

## 📌 Sobre o projeto

Quem trabalha com confeitaria de forma autônoma costuma cuidar de tudo sozinha: receber encomendas, definir receitas, comprar ingredientes, produzir e entregar. Este sistema nasceu para **organizar essa rotina** e tornar o trabalho mais simples e profissional.

### Objetivos

- Centralizar a gestão do negócio em uma única ferramenta
- Reduzir erros e esquecimentos em encomendas e entregas
- Controlar o estoque de ingredientes e evitar faltas na hora de produzir
- Ser simples e intuitivo, mesmo para quem não tem familiaridade com tecnologia
