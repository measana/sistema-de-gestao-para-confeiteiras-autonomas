# 🧁 Sistema de Gestão para Confeiteiras Autônomas

Aplicação web criada para **facilitar o dia a dia de confeiteiras autônomas**, reunindo em um só lugar o controle de encomendas, clientes, produtos, receitas, estoque e agenda, sem planilhas espalhadas e sem anotações perdidas.
---

## 📌 Sobre o projeto

Quem trabalha com confeitaria de forma autônoma costuma cuidar de tudo sozinha: receber encomendas, definir receitas, comprar ingredientes, produzir e entregar. Este sistema nasceu para **organizar essa rotina** e tornar o trabalho mais simples e profissional.

### Objetivos

- Centralizar a gestão do negócio em uma única ferramenta
- Reduzir erros e esquecimentos em encomendas e entregas
- Controlar o estoque de ingredientes e evitar faltas na hora de produzir
- Ser simples e intuitivo, mesmo para quem não tem familiaridade com tecnologia

---

## ✨ Funcionalidades (Requisitos Funcionais)

### 🔐 Autenticação
- Cadastro de usuário
- Login
- Recuperação de senha

### 📊 Dashboard
- Resumo dos pedidos
- Próximas entregas
- Atividades recentes do negócio

### 📋 Gestão de pedidos
- Cadastro, edição e consulta de encomendas
- Registro de produtos, quantidades e personalizações
- Controle de datas (produção, entrega e retirada)
- Acompanhamento por status

### 👩‍🍳 Gestão de clientes
- Cadastro e gerenciamento de dados dos clientes
- Endereços e preferências
- Histórico de pedidos

### 🎂 Catálogo de produtos
- Cadastro e gerenciamento de bolos e doces
- Categorias, sabores e tamanhos
- Imagens e preços

### 📖 Receitas e fichas técnicas
- Registro de receitas com ingredientes e quantidades
- Modo de preparo
- Rendimento e tempo de produção

### 📦 Controle de estoque
- Gerenciamento de ingredientes e materiais
- Controle de quantidades e validades
- Alertas de estoque baixo

### 📅 Agenda
- Visualização das encomendas em calendário
- Organização por datas de produção, entrega e retirada

### 📈 Relatórios
- Relatório de pedidos
- Produtos mais vendidos
- Encomendas concluídas e canceladas
- Consumo de ingredientes

### ⚙️ Configurações
- Informações da confeitaria
- Dados do usuário e alteração de senha
- Preferências do sistema

## 🚀 Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/) (versão LTS recomendada)
- [npm](https://www.npmjs.com/) (já vem com o Node.js)
- [Angular CLI](https://angular.dev/tools/cli)

```bash
npm install -g @angular/cli
```

### Instalação

```bash
# Clone o repositório
git clone https://github.com/measana/sistema-de-gestao-para-confeiteiras-autonomas.git

# Entre na pasta do projeto
cd sgca-projeto

# Instale as dependências
npm install
```

### Executando em ambiente de desenvolvimento

```bash
ng serve
```

Depois, acesse no navegador: **http://localhost:4200**

### Gerando a versão de produção

```bash
ng build
```

Os arquivos serão gerados na pasta `dist/`.
